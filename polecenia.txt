24. Oblicz wiek każdego ucznia
SELECT imie, 
       nazwisko
       data_urodzenia
       TIMESTAMPDIFF(
           YEAR,
           data_urodzenia,
           CURDATE()
       ) AS wiek
FROM uczniowie
ORDER BY wiek DESC;

Funkcja	  Typ zwracany
TIMESTAMPDIFF	  BIGINT (liczba całkowita ze znakiem)
CURDATE()	  DATE (format YYYY-MM-DD w kontekście stringowym, YYYYMMDD jako BIGINT w kontekście numerycznym)

jakie funkcje w sql operują na tekście
W SQL funkcje operujące na tekście służą do **modyfikacji, ekstrakcji, łączenia i analizy** ciągów znaków. Do najważniejszych należą:

*   **UPPER() / LOWER()**: Zmiana wielkości liter (na wielkie lub małe).
*   **SUBSTRING() / LEFT() / RIGHT()**: Wyodrębnianie fragmentów tekstu (od początku, końca lub określonej pozycji).
*   **REPLACE()**: Podmiana jednego podciągu na inny.
*   **CHARINDEX() / PATINDEX()**: Wyszukiwanie pozycji wystąpienia podciągu lub wzorca.
*   **LEN() / DATALENGTH()**: Zwracanie liczby znaków lub bajtów.
*   **CONCAT() / CONCAT_WS()**: Łączenie wielu tekstów w jeden (z opcjonalnym separatorem).
*   **TRIM() / LTRIM() / RTRIM()**: Usuwanie spacji z lewej, prawej lub obu stron.
*   **STUFF()**: Usuwanie i wstawianie fragmentu tekstu w określonym miejscu.
*   **REPLICATE()**: Powielanie ciągu znaków określoną liczbę razy.

Składnia i dostępność niektórych funkcji (np. `CONCAT_WS`, `STRING_AGG`) może się różnić w zależności od systemu zarządzania bazą danych (MS SQL Server, MySQL, PostgreSQL).


różnice pomiędzy char length a length w sql

**LENGTH** i **CHAR_LENGTH** różnią się jednostką pomiaru długości tekstu: **LENGTH** zwraca liczbę **bajtów**, a **CHAR_LENGTH** liczbę **znaków**.

W przypadku czysto ASCII oba zwracają ten sam wynik, ale w kodowaniach wielobajtowych (np. UTF-8) różnią się, ponieważ jeden znak może zajmować więcej niż jeden bajt. Poniżej przedstawiono kluczowe różnice w zależności od systemu:

| System | LENGTH | CHAR_LENGTH | Uwagi |
| :--- | :--- | :--- | :--- |
| **MySQL** | Liczy **bajty** | Liczy **znaki** | Długości się różnią dla Unicode/Emoji. |
| **PostgreSQL** | Liczy **znaki** | Liczy **znaki** | Dla bajtów należy użyć `OCTET_LENGTH()`. |
| **SQL Server** | Brak funkcji `LENGTH` | Brak funkcji `CHAR_LENGTH` | Należy użyć `LEN()` (znaki) i `DATALENGTH()` (bajty). |

**Kiedy używać której funkcji?**
*   Użyj **CHAR_LENGTH**, gdy chcesz sprawdzić limit znaków dla użytkownika (np. walidacja formularza) lub wyświetlić liczbę znaków w interfejsie.
*   Użyj **LENGTH** (lub odpowiednika bajtowego), gdy analizujesz zużycie miejsca w bazie danych, optymalizujesz rozmiary kolumn `VARCHAR` lub pracujesz z danymi binarnymi.

Przykład różnicy w MySQL dla znaku euro (€):
```sql
SELECT LENGTH('€') AS bajty, CHAR_LENGTH('€') AS znaki;
-- Wynik: 3 bajty, 1 znak
```
